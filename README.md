# CVPilot AI — Find What's Holding Your CV Back

Build or upload your CV, get explainable feedback, and export it as a PDF.

**Live demo:** https://shahzaibarshad8688-art.github.io/CVPilot-Ai/

## Features

- Step-by-step CV builder (personal info, experience, education, skills, extra sections)
- CV review with clear, explainable feedback
- ATS-friendly templates and styles
- Job matching
- Built-in CV writing guide (summary, achievements, ATS readability, tailoring, common mistakes)
- Export as PDF
- Your data stays in your browser (localStorage)

## Tech

HTML, CSS, JavaScript (single page).
